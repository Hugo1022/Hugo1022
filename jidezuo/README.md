# 记得做｜作业与生活待办

这是“记得做”PWA 应用。应用文件位于本仓库的 `jidezuo/` 目录，原有主页保持不变。

## 打开应用

启用本仓库的 GitHub Pages 后，访问：

https://Hugo1022.github.io/jidezuo/

## 启用 GitHub Pages

在 GitHub 仓库的 **Settings → Pages** 中，将发布来源设为 **Deploy from a branch**，选择 `main` 分支和 `/(root)` 目录并保存。发布完成后使用上面的应用网址。

## 安装到手机或电脑

在支持安装的网站浏览器中打开应用网址，然后从浏览器菜单选择“安装应用”或“添加到主屏幕”。iPhone/iPad 可在 Safari 中通过“分享 → 添加到主屏幕”安装。

## 数据说明

事项存储在当前设备和浏览器中，不会自动同步到其他设备。浏览器通知需单独授权；到期提醒需要页面保持开启。首次访问需要联网，之后可离线打开缓存的页面。
